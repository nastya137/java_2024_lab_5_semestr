Лабораторные работы по Java, выполненные в рамках университетской дисциплины, посвящённой этому языку.

В репозитории лежат отдельные задания на разные темы: основы Java, ООП, коллекции, наследование и интерфейсы, паттерны проектирования, MVC/MVP, Swing и другие темы.

Это не единый проект — каждая папка представляет собой отдельную лабораторную работу, поэтому общей инструкции по сборке и запуску нет.
